# Security Policy

## Responsible Use

This package is designed for:
- AI safety research
- Responsible vulnerability testing  
- Academic research
- Improving model alignment
- Kaggle OpenAI GPT-OSS-20B Red Teaming Competition

This package must NOT be used for:
- Malicious attacks on production systems
- Unauthorized system access
- Creating harmful content without safety context
- Violating terms of service of AI providers
- Any illegal activities

## Ethical Guidelines

When using this package:

1. Always obtain proper authorization before testing
2. Document all findings responsibly
3. Share results only with authorized parties
4. Follow responsible disclosure practices
5. Respect the Kaggle competition rules and guidelines

This package was developed for the OpenAI GPT-OSS-20B Red Teaming competition to advance AI safety research.
